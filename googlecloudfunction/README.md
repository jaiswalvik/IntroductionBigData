## Project Description



This project uses Google Cloud Platform (GCP) and Cloud Function to:

1. Download a text file from Google Cloud Storage (GCS)

2. Identify the longest line(s) in the file

3. Display and save the results back to GCP

4. Log the output in Google Logs Explorer.



If multiple lines share the maximum length, all are reported.





## Files Included

- `main.py` → Python script used in google function  

- `outputfile.pdf` → Output file containing longest line(s)  

- `README.md` → Documentation file

- 'log_screen_shot.png' - Screenshot of Google Logs Explorer
