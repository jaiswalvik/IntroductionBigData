## Project Description

This project uses Google Cloud Platform (GCP) and PySpark in Dataproc cluster to:

1. Read 2 text files from Google Cloud Storage (GCS) that are customer and transaction data.

2. Perform preprocessing, cleaning, joining & aggregation on the customer and transaction files

3. Display and save the results back to GCS.

4. Use dataframe to perform various operations and store the output to GCS.

## Files Included

- All the CSV files  → Output files from the various operations  

- Dataproc-job_1, Dataproc-job_2 & Dataproc-job_3  → Screenshot of logs of dataproc job executed on cluster

- Customer-Transaction.py  → python script for the assignment.
