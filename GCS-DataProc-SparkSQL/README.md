## Project Description

This project uses Google Cloud Platform (GCP) and PySpark in Dataproc cluster to:

1. Read 3 text files from Google Cloud Storage (GCS) that are customer and transaction data.
2. Perform aggregation on transaction & SCD analysis on the customer files.
3. Display and save the results back to GCS.
4. Use Spark SQL to perform various operations and store the output to GCS.

## Files Included

* All the CSV files  → Output files from the various operations
* Log\_1, Log\_2 → Screenshot of logs of dataproc job executed on cluster
* SparkSQLAssignment.py  → python script for the assignment.
* README.md → Documentation file
